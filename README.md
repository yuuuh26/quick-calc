# QUICK CALC v1.0

Made by YUU

Android Chromeを主対象にした、計算式・途中結果・画像コピー付きの電卓です。静的ファイルだけで動きます。計算データの外部送信、ログイン、広告、アクセス解析、クラウド同期はありません。

## 主な操作

- 入力中も計算結果が更新されます。乗算・除算を先に計算します。
- `=`で確定して履歴に保存。確定後の数字は新しい計算、演算子は結果からの継続です。
- `200 + 10% = 220`、`200 − 10% = 180`、`200 × 10% = 20`、`200 ÷ 10% = 2000`。
- 加算・減算の右辺が単独の%の場合は、そこまでの左辺の値に対する割合です。例：`100 + 20 + 10% = 132`。乗算・除算に含まれる%は通常の割合です。例：`200 + 10% × 2 = 200.2`。
- `±`は現在入力中の数の正負を切り替えます。負数は`−`で表示します。
- `M+ / M−`は現在の途中結果または確定結果をメモリーへ加算・減算。`MR`は現在の数値欄への呼び出し、`MC`は消去です。`AC`では消えません。
- 「計算画面をコピー」は、式と結果だけのPNGをコピーします。対応しない環境ではテキストへ切り替えます。コピー自体が禁止されている場合も、手動選択用の文字を表示します。
- 未完成の式をコピーすると「途中結果」と明示します。
- コピーは数字キーの下、履歴と同じ段にあります。その下にMキー4種類の説明を常時表示します。
- 履歴は最大100件。タップで元の式と内部精度の結果を再利用できます。
- `0–9 . + - * / % Enter = Backspace Escape`をキーボードから使えます。

## 精度と保存

Decimal.js v10.6.0を同梱し、内部精度40有効桁、四捨五入（ROUND_HALF_UP）で計算します。表示は最大15有効桁で、不要な末尾の0を除きます。非常に大きい数や小さい数は指数表記です。次の演算・履歴・Mメモリーでは表示前の内部値を使います。循環小数などは内部40桁で丸められます。入力は1数値80文字、計算式は1200文字までです。結果の指数が±9999を超える場合はエラーにします。

メモリー・履歴・テーマを、このアプリ専用のlocalStorageキーに保存します。サイトデータ削除・端末変更・ブラウザ変更では引き継がれません。保存が許可されない環境では、通知して一時利用を継続します。計算中の式は保存対象ではありません。

## 公開先

公開URL：`https://yuuuh26.github.io/quick-calc/`

リポジトリ：`yuuuh26/quick-calc`

**GitHubへの反映・Pages公開・公開URLでの起動確認は完了しています。** 公開版で小数演算、演算優先順位、メモリーと履歴の保持、コピー成功表示、オフライン準備完了を確認しました。主要16ファイルが検証済みのローカル版と一致しています。Android・Windows実機のインストールと、実アプリへの画像貼り付けは未確認です。

GitHub Pagesは`main`ブランチのルートから配信する構成です。新規リポジトリを作成してソースを反映した後、Settings → Pages → Deploy from a branch → main / (root)で公開します。`index.html`や`manifest.webmanifest`をリポジトリ直下に置きます。計算履歴やメモリーはリポジトリへ送信されません。

PWAの`id / start_url / scope`はすべて`/quick-calc/`です。別名のパスへ公開する場合は3項目とAboutの公開URLを一緒に変更してください。通常アイコン192/512、maskable 512、favicon 32、apple-touch-icon 180を同梱しています。

ホーム画面への追加は、右上の情報ボタン（ⓘ）→「ホーム画面に追加」から試せます。Chromeが追加確認を提供している場合に、ボタンから確認を開きます。確認が提供されないだけで「インストール済み」と推測はせず、追加方法を表示します。Chrome側で「インストール済みなのに開けない」となる端末について、この入口での解消は実機未確認です。

## ローカルで試す

HTMLを直接ダブルクリックする方法では、モジュールやPWAが正しく動かないことがあります。親フォルダで以下を実行します。

```sh
python3 -m http.server 8765
```

ブラウザで`http://localhost:8765/quick-calc/`を開きます。初回読み込み後、情報欄でオフライン準備が完了していることを確認してください。

## 自動テスト

Node.js 20以上で、アプリのフォルダ内から実行します。アプリの実行にNode.jsは必要ありません。

```sh
npm test
npm run check
```

テスト用の依存を追加した場合は、ブラウザ検証も実行できます（ブラウザ検証時だけネット取得が必要です）。

```sh
npm install --no-save playwright
npx playwright install chromium
node tests/browser.mjs
```

`tests/browser.mjs`が検証用ローカルサーバーを自動で起動します。実際の公開URLを検証する場合は、環境変数`QUICK_CALC_TEST_URL`に設定します。ブラウザ検証はテスト用データを対象URLのブラウザ内へ保存・削除します。既存の個人データのある通常ブラウザでは実行しないでください。検証は専用の新しいブラウザコンテキスト内で実行します。

`tests/oracle-corpus.json`はPython標準decimalによる独立した800式の正解集です。生成器は`tests/oracle.py`です。`eval()`はアプリにも生成器にも使用しません。

## 実機での最終確認

Android ChromeとWindows Chromeで、以下を確認してください。

1. `12.5 × 8 + 320 ÷ 4`を入力し、`=`前も後も180になる。
2. 「計算画面をコピー」を押してChatGPTなどへ貼り付ける。式と答えだけがPNGで表示され、ボタンが入らない。
3. `100 × 3 =` → M+、`250 × 2 =` → M+、AC → MRで800。ACでもMが残り、MCで消える。
4. Androidでは情報ボタン（ⓘ）→「ホーム画面に追加」またはChromeのメニューから追加し、他のPWAと別アプリになる。
5. 初回準備後、ネット接続を切って再起動し、計算・M・履歴・コピーを確認する。

これらの実機項目と公開URLでの確認が終わるまで、仕様の最終受け入れ条件をすべて満たしたとは扱いません。
